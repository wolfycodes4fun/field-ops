# Asset Service 😵‍💫

## Prerequisites

* Python and the subsequent modules, pip and venv installed.
* Docker
* Run 'bash scripts/postgres-init.sh'
* Run 'bash scripts/migrate-schema.sh' (installs all necessary libraries to run app, please read the script comments for more information)

Currently the only service under development. To run service, execute command:  
    python services/asset-service/app.py
